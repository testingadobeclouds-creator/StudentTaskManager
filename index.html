Got Questions?

Frequently Asked Questions

Does it work without an internet connection?

Yes! The entire application is offline-first. All your tasks, subjects, notes, and study stats are stored securely in your browser's LocalStorage and load instantaneously.

How does Google Firebase Authentication work?

You can sign in securely using Google or your email. Once you paste your Firebase credentials into js/firebase-config.js, authentication seamlessly connects to Google's cloud infrastructure.

Can I backup or export my tasks?

Absolutely. You can export your entire database to a JSON file at any time with a single click, and restore it on any device or browser.

Is this app free to use?

Yes, it is 100% free and open, built specifically for students with zero advertisements and zero subscription paywalls.

    About

    Learn more about this application

    Student Task Management System

    A lightweight, offline-capable web application for students to organize and track academic and personal tasks.

    Features

    • Create, edit, and delete tasks
    • Mark tasks as complete/in-progress/pending
    • Set priorities (Low, Medium, High)
    • Search and filter tasks
    • Sort by due date, priority, status, or recent
    • Dashboard with statistics
    • Dark/Light mode
    • Data persists in browser LocalStorage
    • Works offline after first load
    • Fully responsive for mobile and desktop

    Technologies

    • HTML5 - Semantic markup
    • CSS3 - Custom properties, Grid, Flexbox
    • Vanilla JavaScript (ES6+)
    • LocalStorage API

    Data Privacy

    All data is stored locally in your browser. No data is sent to any server. Your tasks remain private and under your control.
